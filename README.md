## Быстрый старт

1. Скачайте `Eksperiment404.exe` из [последнего релиза](https://github.com/coder-smookki/Godot-GameJam-Voenmeh-2026/releases/latest)
2. Запустите файл. Установка не нужна, игра лежит в одном файле
3. Windows может показать предупреждение SmartScreen, потому что файл не подписан: «Подробнее», затем «Выполнить в любом случае»

| Клавиша | Действие |
|---|---|
| `A` `D` или стрелки | Идти |
| `Пробел` | Прыжок, дальше в диалоге |
| `W` | Войти в дверь |
| `E` | Говорить, взять, выбрать |
| `Q` + левая кнопка мыши | Отладчик: время замедляется, выстрел по курсору |
| `Tab` | Телефон: журнал решений, концовки, коллекции |
| `Esc` | Пауза |
| `F1` | Меню разработчика |

Сохранение лежит в `%APPDATA%\Eksperiment404`. Игра сохраняется сама: при входе в комнату и после каждого решения.

## Что уже работает

- Состояние мира по разделу 09 дизайн-документа: 16 переменных, метод игрока от -6 до +5, три линии ЛАБЫ, правила восьми концовок и таймера финала
- Экран развилки с ценой каждого варианта для шести решений: P4, P5, P6, P9, P11, P12. Выбор пишется в журнал, показывается тостом и сохраняется, перед развилкой делается снимок для переигрывания
- Сохранения: одно прохождение и отдельный профиль с открытыми концовками. Испорченный файл не роняет игру
- Заражение этажей: +1% в минуту там, где героя нет, предел роста 85%, лечение тотемами
- Пролог на заглушках: вестибюль, аудитория Н2, коридор 1 этажа, крыша с тремя терминалами. Запуск ЛАБЫ, 60 секунд до заражения выхода (концовка №1), отладчик, тотем ERROR с волной восстановления, двери с условиями
- Экран концовки и слайды эпилога: вариант слайда выбирается по решениям
- Телефон: журнал решений со шкалой метода, сетка концовок, коллекции
- Меню разработчика (`F1`): любая переменная мира, любой экран развилки, переход к терминалам, любая концовка, сводка финального боя. Все восемь концовок проверяются за несколько минут

Персонажи и предметы пока нарисованы цветными заглушками, как на макетах дизайн-документа: пурпурная пилюля - Дима, коричневая - Капи, серые - остальные.

## Как устроено

```text
Автозагрузки (src/core), порядок важен
  World       переменные развилок, счётчики, отметки, часы; method(), laba_line(), ending()
    |  сигналы deciding, decided, changed, marked
    v
  Journal     записывает решения
  Infection   заражение этажей
  SaveSystem  снимок перед развилкой, автосохранение после решения, профиль
  Game        новая игра, продолжение, переходы между комнатами, показ концовок
  Story       таблица «отметка -> задание и последствие»
  Ui          задания, тосты, диалог, развилка, телефон, пауза, меню разработчика

Комната (src/world/rooms/room_<код>.tscn)
  Backdrop -> Props (двери, предметы) -> Actors (герой, Капи, тотемы) -> Spawns
  объекты ставят отметки и вызывают World.choose(), сами сюжетных флагов не хранят
```

| Часть | Что делает |
|---|---|
| `src/core/world.gd` | Единственное хранилище сюжетного состояния. Проверяет значения по схеме, считает метод, линию ЛАБЫ, концовку и таймер |
| `src/core/save_system.gd` | Сохранение в JSON через временный файл, проверка данных при загрузке, снимки развилок, профиль |
| `src/core/condition.gd` | Условие одной строкой для дверей и предметов: `logunova != '' and zeml != ''` |
| `src/core/final_plan.gd`, `src/core/epilogue.gd` | Кто помогает на крыше и какой вариант слайда показать: чистые правила без сцен |
| `src/data/` | Каталоги развилок, концовок и локаций. Тексты и сцены находятся по соглашению об именах |
| `src/ui/` | Каждый экран в своей папке: сцена и скрипт рядом. Экраны поверх игры наследуют `Modal` и ставят мир на паузу |
| `src/world/interact/` | `Interactable` и наследники: дверь, выход (P1), персонаж, одноразовый объект, терминал концовки |

Новая комната подключается добавлением файла `src/world/rooms/room_<код>.tscn`: каталог локаций находит сцену по коду, двери ведут в неё по тому же коду.

Игра рисуется в 480×270 и растягивается целым множителем, поэтому пиксели остаются ровными. Используется рендерер Compatibility: он работает на старых и встроенных видеокартах. Интерфейс обновляется по сигналам мира и заражения, покадровой обработки у него нет.

## Запуск из исходников

Нужен [Godot 4.7.2](https://github.com/godotengine/godot/releases/tag/4.7.2-stable), обычная версия без .NET.

```sh
git clone https://github.com/coder-smookki/Godot-GameJam-Voenmeh-2026.git
cd Godot-GameJam-Voenmeh-2026
git switch dev
godot --path . --import     # первый импорт ресурсов
godot --path .              # запуск игры
godot --path . -e           # открыть редактор
```

## Ветки и релизы

Работа идёт в ветке `dev`. Когда этап готов, открывается pull request из `dev` в `main`.

| Событие | Что происходит |
|---|---|
| Коммит в `dev` или другую ветку, кроме `main` | Линтеры, тесты и сборка `Eksperiment404.exe`. Файл лежит в артефактах запуска 14 дней |
| Pull request в `main` | Те же линтеры, тесты и сборка на результате слияния |
| Слияние pull request в `main` | Сборка `.exe` и GitHub Release: заголовок релиза берётся из заголовка pull request, описание из его описания, тег `v0.<номер pull request>` |

Версия сборки видна в главном меню: `dev-<коммит>` или тег релиза.

## Проверка качества

```sh
pip install "gdtoolkit==4.5.0"
gdformat --check src tests      # единый формат
gdlint src tests                # правила именования и стиля
godot --headless --path . --import
godot --headless --path . res://tests/test_runner.tscn   # тесты, код выхода 1 при провале
```

- Тесты покрывают правила метода и концовок, заражение, сохранения с испорченными файлами, каталоги, загрузку всех сцен и сквозной проход пролога: новая игра, двери, запуск ЛАБЫ, тотем, концовки, продолжение
- Тест каталогов падает, если у ключа из каталога развилок, концовок, локаций или эпилога нет текста в `text/ru.po`
- В коде допускаются только комментарии-описания классов и функций (`##`). Это проверяет CI

## Куда класть арт и тексты

| Что | Куда |
|---|---|
| Спрайты, фоны, иконки | `assets/` по подпапкам: `characters/`, `rooms/`, `ui/`. В сцене узел-заглушка `Body` или `ColorRect` заменяется на `Sprite2D` |
| Звуки и музыка | `assets/audio/` |
| Шрифт | `assets/fonts/`, затем указать его в `src/ui/theme/theme.tres` |
| Тексты интерфейса, развилок, концовок, названия локаций | `text/ru.po`: меняется только строка `msgstr`, ключ `msgid` остаётся |
| Цвета | `src/ui/theme/palette.gd` |

Размеры из дизайн-документа: экран 480×270, герой и преподаватели 24×48, дверь 38×72, портрет в диалоге 64×64.

## Ограничения

- Собраны 4 локации из 46. Дверь в несобранную локацию сообщает об этом
- Нет боёв с боссами, стелса, двух миров, клонов, лифта, «Выбора главы» и «Новой игры+»: для них готовы только правила и данные
- Диалоги показывают заглушку «Текст в работе». Плагин для файлов диалогов ещё не подключён
- Отладчик умеет только стрелять. Режим скана и редактирования значений не сделан
- Тексты слайдов концовок и эпилога пока заглушки
- Сборка есть только для Windows x86_64, файл не подписан
